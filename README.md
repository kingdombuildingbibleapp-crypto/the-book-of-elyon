# The Book of Elyon

A chronological collection of scripture: 82 books ordered by their approximate date of composition, with the KJV (1769, with the 1611 Apocrypha), the Douay-Rheims (Challoner), and R.H. Charles's translations of 1 Enoch and Jubilees. All texts are public domain.

- `data/elyon-data-v1.json` — the source data (books, dates, introductions, text).
- `build.py` — splits the data into `public/data/` (one file per book) for the reader.
- `public/index.html` — the reader: cover, contents, references and credits; continuous page numbers; translations; Greek alternate readings for 1 Enoch; the **Ask Me** chat and **double-tap verse breakdowns**.
- `netlify/functions/` — the AI endpoints (`/api/ask`, `/api/verse`), calling Claude Sonnet 5.5 through the Anthropic SDK. Verse breakdowns are cached in Netlify Blobs, so each verse is generated once.

## AI setup

Add `ANTHROPIC_API_KEY` in Netlify under Site configuration → Environment variables (scope: Functions, mark as secret). The key never reaches the browser.

## Run locally

```bash
python3 build.py
```

```bash
cd public && python3 -m http.server 8080
```

## Deploy

Netlify runs `python3 build.py`, publishes `public/`, and bundles `netlify/functions/` (see `netlify.toml`). Run `npm install` first when deploying from your own machine.

## Accounts, notes, study plans and daily videos (Convex)

Sign in/out, notes, study plan progress and the Today page's videos are
stored in a [Convex](https://convex.dev) backend (`convex/`). The reader
works without it: until `public/config.js` has a Convex URL, the Sign in
button is hidden and those pages say accounts are coming.

- `convex/schema.ts` tables; `convex/auth.ts` email and password sign-in
- `convex/notes.ts`, `convex/plans.ts`, `convex/users.ts` (account deletion)
- `convex/videos.ts` the approved YouTube channels for "Word for Today" and
  "Worship"; a cron (`convex/crons.ts`) reads their feeds every 3 hours
- `convex/planCatalog.ts` is generated by `build.py` from the plans there
- `src/elyon-client.js` the browser side, bundled to `public/js/elyon-client.js`
- `public/features.js` the Today, Study Plans, Topics and My Notes pages
- `public/topics.json` curated topics and the verse-for-today list

One-time setup (on a computer that can reach Convex):

```bash
npm install
npx convex dev          # sign in to Convex, create the project, then Ctrl+C
node scripts/setup-auth.mjs
npx convex deploy       # creates the production backend
node scripts/setup-auth.mjs --prod
```

Then put the production URL (`https://….convex.cloud`, shown by
`npx convex deploy`) in `public/config.js` and deploy the site.

Checks: `npm test` (backend tests), `npm run typecheck`, `npm run build`.
